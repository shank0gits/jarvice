# JARVIS LOCAL AI

A futuristic Iron Man inspired AI assistant built using HTML, CSS and JavaScript.

---

# Features

- Voice Recognition
- Text To Speech
- Gemini AI Support
- Ollama Local AI Support
- Animated Jarvis UI
- Real Time Clock
- Particle Background

---

# Install Ollama

Download Ollama:

https://ollama.com

Install it on your computer.

---

# Download AI Model

Open CMD and run:

```bash
ollama run phi3
```

OR

```bash
ollama run llama3
```

---

# Run Ollama

Double click:

start-ollama.bat

---

# Run Project

1. Open project in VS Code
2. Install Live Server extension
3. Right click index.html
4. Click "Open with Live Server"

---

# Recommended Models

| Model | Speed | Quality |
|---|---|---|
| phi3 | Fast | Good |
| gemma:2b | Very Fast |
| llama3 | Slower | Best |
